# User Guide - StyleForge Virtual Outfit Designer SaaS

Welcome to StyleForge! This guide walks you through designing outfits, calculating production costs, managing fabric inventory, and collaborating with your team.

## 1. Virtual Outfit Studio

1. Navigate to **Outfit Studio** from the left navigation bar.
2. Select a garment preset (Banarasi Saree, Anarkali Kurti, Evening Gown, Shirt, Skirt, Biker Jacket, Trousers) from the left panel.
3. Click and drag the garment onto the croquis mannequin silhouette.
4. Customize colors using the color picker in the right **Garment Styling** panel.
5. Drag transformation handles to resize or rotate the garment.
6. Click **Save Design** to store your canvas state in the database.
7. Click **Export Tech Pack** to print or save a factory production spec sheet.

## 2. Production Cost Calculator (BOM)

1. Navigate to **Production Costing**.
2. View itemized fabric, trim, tailor labor hours, and cutting waste percentages.
3. Observe real-time calculated wholesale price, suggested retail price, and profit margin percentages.
4. Click **Add BOM Item** to include custom buttons, zippers, or embellishments.

## 3. Fabric Inventory & Reorder Alerts

1. Navigate to **Inventory & Fabrics**.
2. View current yardage stock levels for silk, velvet, cotton, and organza.
3. Fabrics falling below their minimum threshold display a **LOW STOCK** alert.
4. Record stock movements (incoming shipments, cutting usage, returns).

## 4. Design Approval Workflow

1. Navigate to **Approvals Workflow**.
2. Review the 3-stage pipeline: Concept Review → Fabric & Costing Approval → Executive Sign-off.
3. Reviewers can approve, reject, or request changes with comments.
